# BUG-006: Checkout can be started with an empty cart

| Field | Value |
|---|---|
| Severity | Major |
| Priority | Medium |
| User / Browser | standard_user / Chrome (latest), desktop |
| Related test case | TC37 |
| Status | To Do |

## Steps to Reproduce
1. Login as standard_user / secret_sauce
2. Do not add anything; click the cart icon
3. Click Checkout and complete the form

## Expected Result
Checkout is blocked or the user is warned that the cart is empty.

## Actual Result
The checkout flow proceeds and an order with zero items can be completed (verify on the live site).
