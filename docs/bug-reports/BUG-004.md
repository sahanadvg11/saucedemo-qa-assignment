# BUG-004: problem_user: Last Name cannot be entered at checkout, blocking purchase

| Field | Value |
|---|---|
| Severity | Critical |
| Priority | High |
| User / Browser | problem_user / Chrome (latest), desktop |
| Related test case | TC41 |
| Status | To Do |

## Steps to Reproduce
1. Login as problem_user / secret_sauce
2. Add an item, open the cart, click Checkout
3. Type a First Name, then a Last Name, then a Postal Code
4. Click Continue

## Expected Result
All three fields keep what was typed and Continue goes to the order overview.

## Actual Result
After typing First='Test', Last='User', Postal='560001', the fields contain First='r', Last=''. After Continue, URL is https://www.saucedemo.com/checkout-step-one.html with error: Error: Last Name is required.
