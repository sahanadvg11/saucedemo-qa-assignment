# BUG-003: problem_user: Add to cart / Remove does not work for some products

| Field | Value |
|---|---|
| Severity | Major |
| Priority | High |
| User / Browser | problem_user / Chrome (latest), desktop |
| Related test case | TC29 |
| Status | To Do |

## Steps to Reproduce
1. Login as problem_user / secret_sauce
2. Click 'Add to cart' on each product in turn
3. Click 'Remove' on the items that were added
4. Watch the button label and the cart badge

## Expected Result
Every Add to cart sets the button to Remove and increments the badge; Remove reverses it.

## Actual Result
Clicked Add to cart on all 6 products; cart badge shows 3. Products whose button did not change to Remove: ['sauce-labs-bolt-t-shirt', 'sauce-labs-fleece-jacket', 'test.allthethings()-t-shirt-(red)']. Products where Remove did not work: ['sauce-labs-backpack', 'sauce-labs-bike-light', 'sauce-labs-onesie'].
