# BUG-005: performance_glitch_user: login and page loads are noticeably slow with no loading indicator

| Field | Value |
|---|---|
| Severity | Minor |
| Priority | Medium |
| User / Browser | performance_glitch_user / Chrome (latest), desktop |
| Related test case | TC14 |
| Status | To Do |

## Steps to Reproduce
1. Open https://www.saucedemo.com/
2. Login as performance_glitch_user / secret_sauce
3. Time the delay between clicking Login and the Products page appearing; compare with standard_user

## Expected Result
Login completes in roughly the same time as standard_user, or a loading indicator is shown.

## Actual Result
Login with performance_glitch_user took about 5.11 s versus 0.16 s for standard_user, with no loading indicator on the Login button.
